# DEV.IL Meter

DEV.IL Meter is a Windows companion for AION2 combat review and character management.

- **Live combat:** follow party DPS and contribution, with the encounter timer and boss health display.
- **Battle review:** browse locally saved fights and inspect total damage, skill damage, and DPS trends. nDPS and rDPS are shown as estimates.
- **Character resources:** view supported observations for characters linked to your DEV.IL account, including server-shared resource counts.
- **Character-specific assists:** save buff and cooldown assist profiles and presets per character.
- **Website connection:** review linked-character resources privately; completed battles appear in anonymous public statistics only when the required sharing consent is enabled.
- **Updates:** check for new releases and use the in-app update flow.
